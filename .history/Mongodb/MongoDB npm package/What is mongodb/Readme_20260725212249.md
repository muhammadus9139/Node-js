# MongoDB npm package

## What is MongoDB?

MongoDB is a NoSQL database that stores data in the form of documents.
It stores data in JSON-like format called BSON (Binary JSON).

MongoDB is used to store, manage, and retrieve large amounts of data easily.

Unlike SQL databases, MongoDB does not use tables and rows.
It uses collections and documents.

### MongoDB Structure

Database
    |
    └── Collection
            |
            └── Document


## Features of MongoDB

- NoSQL database
- Document-based database
- Flexible schema
- High performance
- Easy to scale
- Stores data in BSON format


## Types of Databases

There are mainly two types of databases:


## 1. SQL Database (Relational Database)

SQL databases store data in tables with rows and columns.

Examples:

- MySQL
- PostgreSQL
- Oracle
- Microsoft SQL Server


Example:

Student Table

| ID | Name | Age |
|----|------|-----|
| 1  | Ali  | 20  |
| 2  | Ahmed| 22  |


## 2. NoSQL Database (Non-Relational Database)

NoSQL databases store data in different formats like documents, key-value pairs, graphs, etc.

Examples:

- MongoDB
- Firebase
- Cassandra
- Redis


## Types of NoSQL Databases

### 1. Document Database

Stores data in documents.

Example:
- MongoDB


### 2. Key-Value Database

Stores data as key and value pairs.

Example:
- Redis


### 3. Graph Database

Stores data using nodes and relationships.

Example:
- Neo4j


### 4. Column Database

Stores data in columns.

Example:
- Cassandra


## MongoDB vs SQL Database

MongoDB:
- Collection
- Document
- Flexible structure
- NoSQL

SQL:
- Table
- Row
- Fixed structure
- Relational database
