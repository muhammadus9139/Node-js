# MongoDB Setup

## What is MongoDB Setup?

MongoDB setup means installing MongoDB on the system and preparing it to store and manage databases.

---

# Install MongoDB

## Windows Installation

1. Download MongoDB Community Server
2. Install MongoDB
3. Install MongoDB Compass
4. Start MongoDB service

---

# MongoDB Commands

## Check MongoDB Version

Command:

mongod --version


## Start MongoDB Server

Command:

mongod


## Open MongoDB Shell

Command:

mongosh


## Check Databases

Command:

show dbs


## Create Database

Command:

use databaseName


## Check Current Database

Command:

db


---

# MongoDB Compass

MongoDB Compass is a GUI tool for MongoDB.

It allows us to:

- View databases
- Create collections
- Insert documents
- Update data
- Delete data
- Run queries


Connection:

mongodb://127.0.0.1:27017
